# Supercell Symbol Extractor
A tool created for extracting non-engine symbols from Supercell games builds listed [here](https://github.com/DarKDevz/LeakDay/blob/main/README.md#affected-builds)

## Why?
Its been over a year since this "accident" happened, and i dont see any reason to keep this private, since its (probably) not coming back.
I've seen people struggle to extract these symbols because standard parsers seem to skip them. My method (i think) is the best you can use, so please **credit me if you use this tool**.

Also, because kubune asked me for it :p
